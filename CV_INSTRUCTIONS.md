# CV File Instructions

## How to Add Your CV

To enable the CV download feature:

1. **Create your CV** as a PDF file
2. **Name it exactly**: `Saurabh_Singh_CV.pdf`
3. **Place it** in the PortFolio folder (same folder as index.html)

The download button will automatically work once you add the file!

## File Location
```
PortFolio/
├── index.html
├── styles.css
├── script.js
├── Saurabh_Singh_CV.pdf  ← Add your CV here
└── ... (other files)
```

## Note
If you don't have a CV file yet, the download button will still appear but won't download anything. The button will show the download animation regardless.
