## 🎮 How to Use

### Open Your Portfolio
Just double-click `index.html` - you'll see:
1. Terminal boot animation (3 seconds)
2. Loading percentage (0-100%)
3. System checks
4. "SYSTEM READY" message
5. Portfolio appears!

### Download CV Feature
**IMPORTANT:** Add your CV file first!
1. Create/save your CV as PDF
2. Name it: `Saurabh_Singh_CV.pdf`
3. Put it in the PortFolio folder
4. Click "DOWNLOAD CV" button - it works!

### Hidden Terminal
Press `` ` `` (backtick key) to open terminal

**Commands to try:**
- `help` - See all commands
- `matrix` - Boost Matrix effect
- `hack` - Fun message
- `about` - Your info
- `skills` - List skills
- `exit` - Close terminal
